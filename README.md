# 🌬️ Turbine Power Prediction

An end-to-end Machine Learning project that predicts the **Active Power generated by a wind turbine** based on a given date and time.

The project demonstrates the complete workflow from **data preprocessing and feature engineering → XGBoost model training → model evaluation → Flask web application → deployment on Render**.

## 🚀 Live Demo

🔗 **Live Application:**  
https://turbine-power-prediction.onrender.com/

---

## 📌 Project Overview

Wind turbine power generation varies with time and operating conditions. This project uses historical turbine data to build a machine learning model capable of predicting active power generation for a specified date and time.

The trained model is integrated into a Flask web application where users can select a date and time and receive the predicted active power instantly.

---

## 🎯 Objectives

- Analyze historical wind turbine power-generation data
- Perform feature engineering based on timestamp information
- Train an XGBoost regression model
- Evaluate model performance using regression metrics
- Save and load the trained model using Pickle
- Build a Flask-based prediction interface
- Deploy the application online using Render

---

## 🧠 Machine Learning Approach

### Feature Engineering

The timestamp was converted into multiple time-based features:

- Hour
- Minute
- Day
- Month
- Year
- Day of Week
- Day of Year

These features allow the model to learn patterns in power generation associated with different times and dates.
